下面使用阿里云的 STT + LLM + TTS 组合展示 LiveKit Agents 的标准接入方式。

## 准备环境变量 {id="env"}

仓库根目录的 `.env.example` 列出了全部环境变量。复制为 `.env` 后至少填写：

```bash
DASHSCOPE_API_KEY=sk-ws-your-key
LIVEKIT_URL=wss://your-project.livekit.cloud
LIVEKIT_API_KEY=your-livekit-key
LIVEKIT_API_SECRET=your-livekit-secret
```

不要把真实密钥提交到 Git。开发环境可使用 `python-dotenv` 从 `.env` 加载。`console` 模式不需要 LiveKit 房间凭证。

## 创建 Agent {id="agent"}

```python
from dotenv import load_dotenv
from livekit.agents import Agent, AgentSession, JobContext, WorkerOptions, cli
from livekit.plugins import aliyun


async def entrypoint(ctx: JobContext) -> None:
    await ctx.connect()

    session = AgentSession(
        stt=aliyun.STT(model="paraformer-realtime-v2"),
        llm=aliyun.LLM(model="qwen-plus"),
        tts=aliyun.TTS(
            model="cosyvoice-v3-flash",
            voice="longanyang",
        ),
    )

    await session.start(
        room=ctx.room,
        agent=Agent(instructions="你是一个简洁、友好的中文语音助手。"),
    )
    await session.generate_reply(instructions="主动向用户问好。")


if __name__ == "__main__":
    load_dotenv()
    cli.run_app(WorkerOptions(entrypoint_fnc=entrypoint))
```

这里使用的 `cosyvoice-v3-flash` 和 `longanyang` 同时支持新加坡和中国（北京）。模型与音色必须匹配；
其他 CosyVoice 模型的地域和音色限制见[阿里云插件文档](/plugins/aliyun#tts)。

## 运行 {id="run"}

控制台模式适合先验证麦克风、凭证和模型：

```bash
python agent.py console
```

接入 LiveKit 房间：

```bash
python agent.py dev
```

## 改为 Realtime {id="realtime"}

Realtime 模型自身完成听、理解和说。Qwen Audio 把 `QwenAudioRealtime` 传给 `llm`：

```python
session = AgentSession(
    llm=aliyun.QwenAudioRealtime(
        model="qwen-audio-3.1-realtime-plus",
        voice="longanqian_v3.1",
    )
)
```

不传 `turn_detection` 时默认是 `server_vad`。需要摄像头时改用 `QwenOmniRealtime`，并打开
`room_io.RoomOptions(video_input=True)`。Realtime 模式不需要再配置独立的 STT 与
TTS。详细的音色、轮次检测、开场语和工具调用行为见[阿里云插件](/plugins/aliyun)与
[Realtime 会话](/guides/realtime)。
