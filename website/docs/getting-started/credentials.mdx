## 阿里云百炼 {id="aliyun"}

1. 登录[阿里云百炼 API Key 页面](https://help.aliyun.com/zh/model-studio/get-api-key)。
2. 选择与模型一致的地域和业务空间，创建 API Key。
3. 创建成功时立即保存 Key 与 API Host；新 Key 的明文通常只展示一次。
4. Qwen Audio Realtime 推荐同时记录业务空间 ID，用于专属 WebSocket 域名。

```bash
DASHSCOPE_API_KEY=sk-ws-your-key
# 可选：直接覆盖 Realtime WebSocket 地址
DASHSCOPE_REALTIME_BASE_URL=wss://your-workspace.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime
```

同一个 `DASHSCOPE_API_KEY` 可供本插件的 STT、TTS、LLM 和 Realtime 使用，但该 Key
必须属于已经获得对应模型权限的业务空间。

## 火山引擎 {id="volcengine"}

语音能力先进入[豆包语音控制台](https://console.volcengine.com/speech/app)创建应用并
开通目标服务。控制台会提供 App ID 和 Access Token；LLM 需要在
[火山方舟控制台](https://console.volcengine.com/ark/)创建 API Key。

```bash
VOLCENGINE_STT_APP_ID=your-app-id
VOLCENGINE_STT_ACCESS_TOKEN=your-access-token
VOLCENGINE_TTS_ACCESS_TOKEN=your-access-token
VOLCENGINE_LLM_API_KEY=your-ark-api-key
VOLCENGINE_REALTIME_APP_ID=your-realtime-app-id
VOLCENGINE_REALTIME_ACCESS_TOKEN=your-realtime-access-token
```

TTS 的 `app_id` 当前需要作为构造参数传入；STT 和 Realtime 可从上述环境变量读取。
App ID、Access Token 与已开通资源必须属于同一个语音应用。

## 阶跃星辰 {id="stepfun"}

登录[阶跃星辰接口密钥页面](https://platform.stepfun.com/interface-key)创建 Key，并确认
账号已获得实时语音模型权限。

```bash
STEPFUN_REALTIME_API_KEY=your-stepfun-key
```

## Dify {id="dify"}

在 Dify 应用中打开“访问 API / API Access”，创建该应用的 Service API Key。云端
Dify 默认 API 根地址为 `https://api.dify.ai/v1`；自托管实例使用自己的
`https://<domain>/v1`。

```bash
DIFY_API_KEY=app-your-service-api-key
DIFY_API_BASE=https://api.dify.ai/v1
DIFY_USER=livekit-user
```

`DIFY_USER` 是业务侧终端用户标识，不是 Dify 登录账号；应为每个最终用户提供稳定且
不含敏感信息的 ID。

## FlashTTS {id="flashtts"}

FlashTTS 是自托管服务，不存在统一的云端 Key 申请页面。先按
[FlashTTS 项目文档](https://github.com/HuiResearch/FlashTTS)部署服务，再把服务地址
和部署方设置的 Bearer Token 配置给插件：

```bash
FLASHTTS_BASE_URL=http://127.0.0.1:8000
FLASHTTS_API_KEY=optional-bearer-token
```

<Infobox title="环境变量名称更正" variant="warning">

当前插件源码读取的是 `FLASHTTS_BASE_URL`，不是旧文档中出现过的
`FLASHTTS_API_URL`。

</Infobox>

## 安全建议 {id="security"}

- 只在服务端环境变量或密钥管理系统中保存凭证，不写入 Agent 源码。
- `.env` 仅用于本地开发并保持在 `.gitignore` 中。
- 按项目和环境拆分 Key，生产环境使用最小模型权限与 IP 白名单。
- 日志不要输出 Key、Access Token 或包含 Key 的完整 WebSocket URL。
- 怀疑泄漏时立即在厂商控制台重置或删除凭证。
