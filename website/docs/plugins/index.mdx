## 推荐组合 {id="recipes"}

### 端到端语音

只配置一个 Realtime 模型：

```python
AgentSession(
    llm=aliyun.RealtimeModel(
        model="qwen-audio-3.0-realtime-plus",
        turn_detection={"type": "smart_turn"},
    )
)
```

### 可替换流水线

分别组合 STT、LLM 与 TTS，便于独立更换厂商：

```python
AgentSession(
    stt=volcengine.STT(),
    llm=dify.LLM(user="customer-42"),
    tts=flashtts.TTS(),
)
```

后一种方式更容易控制每个阶段，前一种方式通常有更自然的语气和更低的端到端延迟。

## 维护范围 {id="scope"}

当前仓库只保留上述五个插件目录。Baidu、MiniMax、Tencent、Xunfei 与 Zhipu 已进入
逐步取消支持阶段，新项目不应再依赖这些插件。迁移建议见[维护与迁移](/guides/maintenance)。
