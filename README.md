# 简介

该项目为[livekit-agents](https://github.com/livekit/agents)**实时语音智能体**框架提供中文插件支持。

## 近期修改

停止对以下厂商插件的支持：
- 百度
- MiniMax（迁移到Livekit官方插件支持）
- 腾讯
- 讯飞
- 智谱

新增：
- 阿里云Realtime模型支持
